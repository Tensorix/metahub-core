Less starting over.
More moving forward.

Give your AI the same place to read, write, and pick up where it left off. A simple CLI keeps context useful beyond a single conversation.

  • Small edits. Full context.Read a document, replace a passage, keep the rest.
  • Every change has a history.Review agent writes and undo a logical change group.
Read the agent guide ↗
metahub — agent workflowbash
# Give a new conversation some context
$ mh search "architecture"

# Read before editing
$ mh doc read architecture

# Update just what changed
$ mh doc edit architecture \
    --old "Use a hosted database" \
    --new "Use local SQLite"

# See what your agent changed
$ mh audit
Human-readable in a terminal. JSON for your agent.
