# Website design

A developer-facing product introduction that leads to installation or source documentation. Preserve the existing multicolor modular metahub mark and cobalt accent.

- Background: #fafbf9; foreground: #202724; secondary text: #65716b.
- Primary action: #335cff; borders: #dce2dc; quiet surfaces: #eef2ed.
- Type: self-hosted Manrope (regular and bold), system CJK fallback; monospace only for commands and paths.
- Content width: 1240px maximum. Two-column hero, full-width real product screenshot, paired prose and command example, editorial ownership list, installation section.
- Breakpoints: 1100px and 760px. Mobile stacks sections; product screenshots intentionally scroll within their frame to retain legibility.
- Controls: visible focus ring, localized feedback, semantic tab roles and keyboard navigation. Motion restricted to initial document layers and disabled for reduced motion.
- All product claims are grounded in the repository; the small hero workspace is illustrative, not a claim about actual user data.
