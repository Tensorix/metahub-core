# 26 · 文档内链 `[[doc_id]]`

> 状态：**已实施**(2026-07,提交 `f92debe`)。相关：[system-design/webui-editor.md](../../system-design/webui-editor.md) §3.3、[04-block-level-doc-crdt](../04-block-level-doc-crdt/design.md)

## 0. 一句话

把"引用另一篇文档/另一张表"做成**一等行内 Markdown 语法**:源码里是稳定 id、显示的是实时标题、往返无损、不带 origin,因此改标题不断链、换设备不断链、agent 直接写就行。

## 1. 为什么不是普通链接

粘一条 `http://localhost:7777/#/doc/doc_x` 有三个问题:**带 origin**(换设备/换端口即死)、**显示的是 URL 而不是标题**、**目标改名后文字就骗人了**。而 core 已经有一套三面共用的行内语法(编辑器 / 保存解析器 / 分享渲染),把内链做成其中一个 token,就能一次性获得三面一致 + 无损往返。

## 2. 语法(core,`src/core/md/inline.ts`)

```text
[[doc_design-9fk3]]              → 显示目标当前标题
[[db_tasks-a3f9]]                → 数据库同理
[[doc_design-9fk3|见架构说明]]     → 显式别名覆盖显示文本
```

- **只认 id 形状**:`(doc|db)_[a-z0-9][a-z0-9-]*`,正好是 `newId()` 的产物(slugify 只出 `[a-z0-9-]`,随机后缀是 base36)。因此任意 `[[普通文本]]`、`[[TODO]]` 仍是**字面散文**——不会把用户的双方括号笔记变成断链。
- **优先级必须高于 link**(`rank` 早于 `[t](u)`):两者都以 `[` 开头,`[[id]](x)` 必须读成"内链 + 字面 `(x)`"。
- **内容跨度 = 显示成的纯文本**(有别名取别名,否则取 id)。这样 `stripInlineTokens`(TOC / 搜索 / 摘要)不用特判就把内链摊平了。
- token 携带 `id` 与 `alias` 两个可选字段;转义 `\[[…]]` 保持字面,与其它行内规则一致。

## 3. 标题解析 `src/webui/doc-titles.ts`

CM6 的装饰是**同步**构建的,所以渲染时必须有一张现成的 id→标题表——不能"顺手 fetch 一下"(会闪)。

- `primeDocTitles(docs, dbs)`:`App.reloadNav()` 用它**已经取到**的导航列表白喂进来,零额外请求。
- 没有完整应用外壳的场景(快速笔记窗口、测试)首次查找时惰性自刷新。
- `NAV_INVALIDATE`(任何成功变更,含改名)只把表标记为 **stale**;**stale 期间继续供旧标题**(自动保存时不闪),真的有标题变了才通知订阅者重建装饰。
- `docLinkTitle(id)` 三态:`string`(有标题)/ `null`(确定不存在)/ `undefined`(还不知道)。

## 4. 四个消费面

| 面 | 行为 |
|---|---|
| **编辑器折叠态** `cm6/inline.ts` | 渲染成 `.cm-doclink` 胶囊(`data-doclink=<id>`),显示实时标题;目标不存在时 `.cm-doclink-missing`。点击经 hash 路由**应用内跳转**,缺失目标不跳 |
| **编辑器展开态** | 光标进入即露出 `[[id\|alias]]` 源码(`.cm-doclink-src`,定界符变灰),与其它行内标记的 reveal-to-edit 一致 |
| **表格单元格桥** `webui/markdown.tsx` | 渲染成带 `data-doclink` 的应用内 `<a>`;DOM→Markdown 回写时还原成**原样的** `[[id]]` / `[[id\|alias]]` |
| **分享页** `core/sync/share-render.ts` | 渲染成**惰性 `<span>`**——自动链到目标的分享页会泄露没被分享的东西,所以只留文字 |

## 5. 输入方式

- **`[[` 选择器** `cm6/chrome/doclink-suggest.tsx`:光标锚定的浮层,列出全部文档/数据库标题(读的就是上面那张本地表,**无网络往返**),打字过滤、方向键移动、Enter/点击插入**规范 `[[id]]`**、Esc 或破坏 `[[query` 即关闭。
  - 触发判定:最后一个 `[[` 与光标之间没有闭合括号或嵌套开括号;打了 `|` 也算关门(此后是在写别名,不是在搜标题)。
  - 结构对齐 `slash-menu.tsx`:插件自己在 `document.body` 上挂 `.pop` 浮层,并用**捕获阶段** keydown 拦截导航键,菜单开着时结构 keymap 收不到这些键。
- **粘贴转换**:粘站内链接时 `chrome/upload-paste.tsx` 经 `view.ts` 的 `doclinkFromUrl` 转成内链(内链不带 origin,因此换设备照样活)。
- **分享菜单复制**:复制的是可粘贴成内链的形式。

## 6. 不变量(勿回退)

1. **只认 id 形状**。放宽匹配 = 把用户的普通方括号变成断链;真要改,先想清楚 `stripInlineTokens` 与分享页惰性渲染的连带影响。
2. **doclink 的 rank 必须早于 link**,否则 `[[id]](x)` 会被读成链接。
3. **内容跨度取显示文本**,别改成整个 token —— 摘要/TOC/搜索都依赖它自动摊平。
4. **选择器只读本地标题表**;任何"顺手 fetch"都会让装饰闪烁。
5. **stale 期间供旧标题**——保存触发的 nav 失效不许让正文里的胶囊集体闪一下。
6. **分享页永远惰性**:不自动外链到未被分享的目标。
7. **id 是规范形式**:插入与回写都写 id,别把当时的标题固化进源码。

## 7. 已知留白

- 没有反向链接(backlinks)视图。
- 没有"目标已删除 → 批量修复/替换"的工具,缺失态只是视觉提示。
- 内链不参与全文索引的关联权重(FTS 只索引显示文本)。
