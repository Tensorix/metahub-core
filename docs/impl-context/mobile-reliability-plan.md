# Expo 移动端推进计划

基线：`feat/mobile` / `6d2f59d`，目标目录 `apps/mobile`。日期：2026-10-24。

## 判断与范围

当前为早期在线客户端。基础连接、浏览、记录编辑、看板和文档 WebView 已有实现，本轮先修可靠性与高频流程。在线定位不变，不在本轮实现本地副本、离线同步、数据库结构管理或重写文档编辑器。

## 并行分工与思考预算

| 工作流 | 模型 / reasoning effort | 原因 | 文件边界 |
| --- | --- | --- | --- |
| 浏览、搜索、加载反馈 | gpt-6.1-sol / low | 局部 UI 与请求状态，验收直接 | hooks、home、search、db、BoardView |
| 记录编辑与草稿 | gpt-6.1-sol / medium | 涉及并发写入、脏状态、失败重试与服务端刷新 | record、RecordTextInput、RefField、MultiSelectSheet、HistorySheet、草稿帮助模块 |
| 会话、鉴权、文档恢复 | gpt-6.1-sol / high | 凭证轮换、跨服务器异步结果、共享 SDK 与 WebView 生命周期 | auth、mobile-api、live、layout、settings、scan、ServerForm、doc；最小 SDK 传输接口 |
| 集成与验收 | 主 agent | 检查跨工作流不变量，复核实现和证据 | 计划、集成修复、最终验证 |

不以同一预算处理所有任务；局部修复不升级，高风险状态与凭证逻辑保留足够推理预算。

## 阶段一：本轮实施

1. 记录输入使用可更新的原生状态，远端刷新/历史恢复能更新未编辑字段，不能覆盖未提交草稿。
2. 草稿失败保留、状态可见、重试可用；同一记录写入按序执行，快速修改最终值正确；删除仅在成功后退出。
3. 查询变化不显示旧结果，真实 debounce；请求来源变化隔离旧数据，同一来源刷新保留已有内容。
4. 新建与看板移动防重复、失败可见；移除静默 500 条截断。现有服务端不提供游标分页，本轮完整请求不等于分页能力。
5. 普通 SDK 读写与历史接口统一鉴权，401 续期有去重与有限重试，不能把 token 发送到其他 origin。
6. 切换服务器重置原有界面状态，旧服务器迟到的请求不能改写当前会话；凭证失效可恢复。
7. 文档 WebView 有加载、错误、重试和返回兜底；不宣称已实现网页编辑器的未保存桥接。

## 验收

- 纯逻辑 Bun 测试覆盖写入顺序、失败草稿/重试、鉴权并发与重试上限；新增测试不能依赖原生运行时。
- 共享 SDK 变更运行对应回归测试，保持默认 transport 行为。
- 移动端 typecheck、源文件 ESLint、git diff --check。
- 原生尚需验证：iOS/Android 键盘、输入法组合、返回手势、弹窗、WebView 导航与弱网。未实际运行的检查明确记录为未验证。
- 不提交、不发布、不修改生成的 ios/android 工程。

## 阶段二：完整高频工作流程（后续）

- 服务端游标分页与移动端增量加载，评估大库、排序变化与实时变更的一致性。
- 数据库内搜索与筛选、可配置看板分组和视图持久化。
- 原生文档管理、关联搜索/跳转、最近访问。
- 数据库及字段管理明确支持范围，再独立实施。

## 阶段三：原生体验与发布门禁（后续）

- iOS/Android 实机验收：断网、恢复网络、切后台、token 轮换、服务器切换、长文本、大字体与安全区。
- 建立移动端 CI 和可复现的开发构建/测试数据。
- 基础流程稳定后再完善视觉细节与发布配置。

## 本轮执行结果

第一阶段实现已落在工作区，未提交。

- low：查询防抖、旧结果隔离、加载/错误/重试、新建与移动防重复、首页服务器标识、移除记录 500 条静默限制。
- medium：可更新原生输入状态、串行/合并写入、草稿保留与重试、未保存离开提示、成功删除后返回、历史错误恢复、关联候选搜索及加载反馈。
- high：统一 SDK/历史/SSE 鉴权、并发续期去重、有限重试、过期会话结果隔离、服务器切换重置、凭据更新入口、文档加载失败重试及返回兜底。
- 主 agent 交叉审查并退回修正了搜索伪防抖、保存显示值遮盖远端更新、暂时续期失败终止 SSE、WebView 双重导航栏等问题。
